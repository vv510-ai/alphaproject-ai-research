# 第十课：日线与成交量的实现和操作记录

日期：2026-10-18。范围为 AlphaProject-Lab 的 FR-003 历史走势部分。页面、取数、保存与相关检查已完成；用户已发来实际页面截图。现有生产网站独立运行。

## 1. 日线和成交量是什么，为什么要接入

首页报价像一张价格快照，告诉我们来源最近返回了什么价格。日线把每天的变化排列起来，本课用日 K 线展示：每个交易日期有开盘、最高、最低、收盘四个价格。蜡烛的方块连接开盘和收盘，上下细线伸到最高和最低；收盘高于开盘为红，低于开盘为绿，相等为灰。

成交量是这一天成交的股票数量，本页统一为“股”，不是成交人数，也不是成交金额。上下两幅图共用日期轴，方便把某一天的价格变化和交易量放在一起看；它们提供背景，不能单独证明涨跌原因。

本课使用不复权价格，即保留来源历史价格。分红、送转可能造成跳变，因此不能把整段价格变化直接当作投资收益。只显示北京时间昨日及以前、来源返回且通过校验的记录；没有补造交易日期或未结束的当日日线。

## 2. 你看到的页面怎样读

入口：[电脑页面](http://127.0.0.1:18765/)；同一 Wi-Fi 的[局域网入口](http://10.45.146.38:18765/)。电脑服务需保持运行，换网络后可在页面“在手机打开”中查看地址。启动方式沿用[启动共享自选.cmd](../../启动共享自选.cmd)。

1. 点某只自选的“日线与成交量”。已有数据直接读回；点“获取日线 / 更新日线”才请求来源。
2. 点击图中的一天，或使用“查看哪一天”“前一条”“后一条”。核对下面的四个价格和成交股数；也可以展开逐日数据表。
3. “近 30 条”和“全部”是显示范围操作，点击时同时回到最新一天。拖动图或选旧日期后，仍可再次点击恢复范围。
4. 鼠标移动时，黑色虚线标签显示鼠标所在的日期和价格位置；下方明细以点击或选择的日期为准。右侧红绿数值标签显示最新一条数据，不能与所选旧日明细混为一谈。

**用户本课反馈：**用户回复“看到了这个”，并提供[页面截图](../../evidence/daily-20261018/user-observation.png)。截图显示选中 2026-09-18：开盘 1,262.99 元、最高 1,265.88 元、最低 1,256.10 元、收盘 1,257.12 元，成交量 2,489,100 股；来源原量 24,891 手 × 100。与已保存记录一致。

这确认了用户能看到图和选中日的明细；不据此推定由谁切换了日期，也不代替真实手机验证。下一次可自行点“后一条”，观察日期与五个数字一起变化；无需先回答术语题才能继续学习。

## 3. 用了哪些工具，各自做什么

| 工具 | 在这次开发中的作用 |
| --- | --- |
| Python / FastAPI | 接收网页请求，核对股票和当前自选记录，组织取数与保存 |
| HTTPX | 请求腾讯日线；限制等待时间、返回大小与访问目标 |
| Decimal | 按十进制核对价格、成交股数和金额，避免浮点计算影响单位判断 |
| SQLite | 保存自选、报价和整批日线；程序重启后可继续读取 |
| React / TypeScript / Vite | 制作页面交互、检查数据类型并构建网页 |
| Lightweight Charts 5.2.1 | 绘制日 K 线与成交量；本身不提供行情数据 |
| pytest | 检查错误字段、日期、单位、并发、重启及删除重加等行为 |
| Chrome DevTools | 实际点击页面、检查图与明细、模拟接口失败和窄屏 |

腾讯响应字段参考[AKShare 固定提交的实现](https://github.com/akfamily/akshare/blob/fe10d1decb705e5f43cc8ca3339ca39e580fb8f4/akshare/stock_feature/stock_hist_tx.py)，再用真实样本核对。本课在已有 HTTPX 上实现小适配器，没有把整套 AKShare/Pandas 装入应用环境。图表用[官方库](https://tradingview.github.io/lightweight-charts/docs)，保留所需署名、链接与[第三方许可](../../frontend/public/licenses/third-party-notices.txt)。

## 4. 开发思路与重要取舍

**用户点获取 → 后端核对自选 → 请求原始日线 → 核对身份、日期、四价、单位 → 保存整批与原文 → 图表和明细读取同一批。**

先验证数据，再接图表。本次样本的来源原量中，600519、000001、300750 为手，688981 为股；按对应系数转换后，用成交额除以股数得到的均价核对日内高低范围。来源入口相同不等于两家独立数据源，四个样本也不能证明全市场覆盖。之后每批继续检查，单位或字段对不上就拒用，保留旧批次。

显示和获取分开：打开详情与每 5 秒同步只读缓存，明确点击更新才向来源查询；同一只股票 30 秒内防重复点击。数据库事务只负责短时登记、保存，网络等待在事务外。每次取数绑定这条自选的创建时间和请求标识，删除重加后的旧请求不会写入新记录，离开详情会取消页面请求。

实现中发现并修正了两个显示问题：图表署名样式被原页面策略阻止，现只允许该固定版本的精确样式哈希；范围按钮重复点击不生效，以及两个绘图更新步骤读到旧范围后相互覆盖，现由一次更新统一处理范围和选日。后者先有源码审查，再用实际画布发现遗漏并复验，不能仅凭文字日期一致就称图表正确。
