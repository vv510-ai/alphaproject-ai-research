# 第十三课：让 AI 解释已经发生的事件

2026-10-18。用户要求继续实践开发，解释 AI 怎样读取异动依据、怎样减少胡编，以及设计取舍；让本人操作和核对结果。

## 本课交付

在已保存的异动事件下点击“解释这次异动”，先看到将使用的事实，再按需调用模型。生成结果分为可复算事实、AI 通俗解读、缺少的证据。每段解读可以打开对应证据。刷新读取已有结果，失败明确显示；行情、事件和基础飞书提醒不等待 AI。

范围仅为 AlphaProject-Lab 的事件解释，沿用 FR-004 和 AC-007/008/013。股票无事件时的解释、新闻搜索、自动推送 AI、早盘简报及公网部署不在本课切片内。真实盘中资格 DATA-01 保持原状态。

## 输入与内容边界

1. 后端只按事件编号读取触发时的快照，不读首页最新报价覆盖它。重新核对股票身份、数值、阈值、计算、来源时间与事件时间；缺失或矛盾时停止生成，显示缺什么。
2. 事实表和计算由程序生成，每项有固定证据编号。模型收到的内容以必要的数值、规则、日期和类别为限；来源原文、任意用户指令、密钥及飞书信息不进入提示词。股票名称在页面显示，不借模型记忆补公司故事。
3. 模型用结构化 JSON 返回同一事件编号、证据摘要、关键事实复述及带引用的短解释。程序检查身份、版本、数值、引用和明确的越界内容；不完整、截断、无效引用或不合格内容记失败，不装成成功。
4. 目前没有新闻、公告、成交量和板块对照。原因状态固定为“证据不足”，页面列明缺失项。合成事件始终标演练；允许解释为什么满足规则，不把它说成股票真实上涨。
5. 程序校验与提示词只能减少一部分错误，不能证明任意文字的语义正确。页面保留“需要本人核对”，由用户检查事实、引用和有无凭空推断；不使用模型自评分宣称可靠率。

学习版预算单独记账，不含旁边原项目。按已核验的人民币高峰未缓存价保守估算：输入 2 元 / 百万 tokens，输出 8 元 / 百万 tokens；不把估算叫作平台账单。调用前先在事务中预留输入上界与输出上限对应金额；取得用量后结算估算值，超时或结果未知保留预留量，达到日/月限额停止新调用。旧结果仍可读取。

## 保存与运行

- 新增解释表，保存事件快照摘要、输入哈希、提示词/模型标识、输出、状态、耗时、用量及成本依据。保留每次失败和显式重试之间的关系。
- 请求号持久去重；同一证据、提示词版本和模型的成功结果复用。浏览器刷新、重复点击和多个页面不重复付费。明确重试使用新请求号，并指向失败记录。
- 只由用户手动提交生成；后台执行本次请求，页面轮询读取。网络请求不占数据库事务。服务重启不自动重试付费请求；保留已完成结果。
- API 只接收事件号和请求号等受控字段，不接受任意提示词、模型地址或价格。密钥不进入页面、日志、普通数据库或验证产物。
- 人工核对独立记录，不由 AI 自动标为通过。本人勾选并保存后才显示已核对。

## 必须获取的证据

用例覆盖：原事件与后续报价/规则变化隔离；缺基准、错股票、错日期及来源冲突；JSON/引用/数值错误；超时、拒绝、额度、并发、重复点击、失败重试、重启；旧数据兼容和密钥边界。

真实验证使用当前事件，经过网页、后端、真实模型、保存和刷新回读，逐句核对内容。开发样例和保留核验样例分开。至少一项用户亲手操作；桌面/窄屏验证范围如实记录。执行独立复核后修复并重测相关失败，不以测试总数替代内容检查。
