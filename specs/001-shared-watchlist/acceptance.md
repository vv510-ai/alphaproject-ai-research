# 第八课：共享自选的实际结果与操作方法

日期：2026-10-17。范围：[PRD](../prd.md) FR-001 的共享列表，按用户本课要求完成必要架构、最小页面、开发环境、电脑添加、保存、服务重启和手机读取。其余五个功能没有提前实现。方案见 [plan.md](plan.md)。

## 本课做成了什么

页面输入六位代码，后端从腾讯公开接口核对代码、名称和市场；用户确认后提交，数据库提交成功才显示已加入。电脑和手机都从同一个后端读取，浏览器不独立保存自选。重复项保持一条；移除前有确认；失败保留原列表并给出提示。

实现采用 React + TypeScript + Vite 页面、FastAPI 后端和本地 SQLite 文件。构建后的页面与 API 共用 `18765` 端口，一个应用进程；没有额外数据库服务器、定时器、通知或模型调用。本课只使用来源中的证券身份，不展示价格，不据此声称实时行情已验证。

## 你已经参与和可以复做的操作

本课用户反馈确认电脑和手机能看到共享列表；助手完成实现、测试和重启演示。它们是两类证据，不把助手代做记作用户独立编写。

可以用一只自己熟悉、当前支持的六位代码复做：查找 → 核对名称 → 加入 → 刷新 → 手机读取。再次查同一代码，应显示“已在自选中”。若界面提示失败，先刷新核对实际保存情况再重试；不要仅凭点击过按钮认定成功。

此时可以打开 [backend/app/store.py](../../backend/app/store.py)，找到 `INSERT INTO watchlist`：它把已核对的股票写进“记录本”；`SELECT` 是电脑和手机读记录；`PRIMARY KEY` 则保证同一市场、同一代码不重复。理解这三个动作即可，无须本课记住完整 SQL 语法。

## 下次启动与停止

- 当前电脑入口：[http://127.0.0.1:18765/](http://127.0.0.1:18765/)；同一 Wi-Fi 手机入口：[http://10.45.146.38:18765/](http://10.45.146.38:18765/)。后一个是本次局域网地址，换 Wi-Fi 或 IP 后需要重启并查看页面“在手机打开”。
- 双击[启动共享自选](../../启动共享自选.cmd)：先构建，再启动，最后打开浏览器；服务已运行时会复用当前进程。
- 双击[重启共享自选](../../重启共享自选.cmd)：只停止并重启本工程的服务。脚本核对进程目录、启动参数和创建时间，避免误停其他应用。
- 双击[停止共享自选](../../停止共享自选.cmd)：停止后手机暂时无法访问，列表仍保留。关闭网页窗口不会自动停止后台服务。
- 列表位置为 `.runtime/watchlist.sqlite3`，不要删除它来“刷新”。电脑休眠、关机或服务停止时入口不可用。新电脑首次准备依赖再用[准备开发环境](../../准备开发环境.cmd)，日常无需重复安装。

本次没有改系统防火墙，没有公网端口映射，没有改旁边生产网站。局域网可到达这个入口的人可操作同一列表，这是当前个人练习的访问范围；后续公网范围另行决定。

## 开发命令

在 `D:\Desktop\量化交易系统\AlphaProject-Lab` 打开 PowerShell：

```powershell
# 检查当前服务，或启动本课页面（默认先构建）
.\.venv\Scripts\python.exe -X utf8 scripts\lab.py status
.\.venv\Scripts\python.exe -X utf8 scripts\lab.py start

# 验证后端的保存与失败路径，使用临时数据库
.\.venv\Scripts\python.exe -X utf8 -m pytest -q

# 修改页面后检查类型并构建
npm.cmd --prefix frontend run build
```

可选热更新入口是 `npm.cmd --prefix frontend run dev`，只用于开发电脑；保持后端在 `18765`，API 经 Vite 转发。正式的电脑/手机实测使用已构建页面的 `18765` 入口，本轮没有把开发端口作为手机验收入口。

实际环境：Python 3.12.10 / SQLite 3.49.1 / Node 24.15.0 / npm 11.12.1。后端测试有 1 条 Starlette 关于 TestClient 使用 httpx 的弃用提示，14 项检查仍全部通过；当前未为消除提示升级另一套 HTTP 客户端。依赖锁文件保留本次安装结果，后续环境改变时再核验兼容性。
