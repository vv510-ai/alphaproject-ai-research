# 本地改动与贡献边界

本表描述本地版本相对课程基线的变化，不能证明每一行由某个人独立手写。面试时须区分需求提出、工具生成、本人阅读修改和本人实测。

| 范围 | 上游已有 | 本地版本增量 | 解释重点 |
|---|---|---|---|
| 模型调用 | provider 抽象、主备本地降级 | DeepSeek参数、SDK重试控制、超时和输出限制 | 为什么重试会叠加等待 |
| 简报 | 数据块组装、模板、调度 | 字段适配、估算成本检查及记账 | 软预算与并发超支 |
| 数据 | 行情/K线/新闻结构 | 当前接口与字段适配、错误处理 | 上游变更如何传播 |
| SQLite | 持久化与仓储结构 | 连接显式释放 | 事务退出不等于连接关闭 |
| 本地入口 | 原应用 | Windows运行与静态前端托管入口 | 服务身份与健康检查 |

精确文件比较见 `source-manifest.json`，比较包含 unchanged/modified/added，并保存发布文件 SHA-256。
